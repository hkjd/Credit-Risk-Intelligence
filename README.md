# Credit-Risk-Intelligence

🧠 Project Overview

This project delivers an end-to-end credit risk analytics solution designed to support risk-based lending and portfolio monitoring.
It integrates multiple relational datasets, engineers behavioral risk indicators, and visualizes actionable insights through interactive Power BI dashboards.

🛠 Tech Stack

Power BI – Data modeling, DAX, visualization

SQL – Data integration, feature engineering

CSV / Relational Data – Synthetic banking datasets

📊 Key Features

Integrated 5+ relational datasets covering clients, loans, repayments, and transactions

Built 12+ DAX risk metrics including utilization, default rate, and delinquency indicators

Delivered 4 interactive dashboards with 8+ KPIs for portfolio and client risk analysis

Enabled early-risk detection and data-driven credit decisions
